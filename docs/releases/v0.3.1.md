# mockryx v0.3.1

The `mockryx` binaries and the image, `ghcr.io/taipanbox/mockryx`, are built on Go 1.27.3. Go 1.27.3 fixes GO-2026-6809, a vulnerability in `crypto/x509`, and the v0.3.0 release was built on Go 1.27.2. Nothing else changes in behaviour: no flag, finding, exit status or file format moves.

## Changed since v0.3.0

- #83, `build: Go 1.27.3 for GO-2026-6809 in crypto/x509`. The `go.mod` toolchain, the Go version of CI and of the release workflow, and the Dockerfile's Go version move to 1.27.3, and the gate anchors that named the old pin move with them.

No other commit lies between the v0.3.0 tag and this release.

## Upgrade

Pull `ghcr.io/taipanbox/mockryx:v0.3.1` in place of `v0.3.0`, or download the binary for your platform from this release. No setting, stored state or wire format changes, so there is nothing to migrate. To roll back, run v0.3.0 again.

Whether a given v0.3.0 binary reached the affected `crypto/x509` code was not measured. This release makes the question moot by moving the toolchain, and it is the way to close GO-2026-6809 in the published artifacts.

Full changelog: https://github.com/TAIPANBOX/mockryx/compare/v0.3.0...v0.3.1
